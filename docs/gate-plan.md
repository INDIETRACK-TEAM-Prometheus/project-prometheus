2026-10-27 KST. 목표는 SRS v1.1 G0–G5 전체 통과다. 범위·수치·시험 조건을 실행 결과에 맞춰 낮추지 않는다. 아래는 완료 주장이 아닌 작업표이며 실제 판정은 CTO_REVIEW와 원본 증거를 따른다.

## 실행 원칙

- 자동 검증에서 실제 카메라를 가짜 장치로 바꾸지 않는다. 합성 입력은 명시적으로 합성이라고 기록한다.
- Aria 공식 MPS의 과거 timestamp가 인과성을 보장하지 않는다. 후처리 결과는 `offline_assisted`로 격리한다.
- 눈/얼굴 원본은 기록하지 않는다. 사용자 교정·품질 수치는 관리·검증 결과이며 모델 의도 입력으로 보내지 않는다.
- 원격 장면 전송은 명시적 동의 후에만 활성화한다. 키는 서버 프로세스 환경에만 존재한다.
- 브라우저의 렌더 콜백은 실제 패널 발광 측정이 아니다. 미측정 표시 불확실성을 0으로 두지 않는다.
- 사용자 개입이 필요한 시험을 기다리는 동안 독립 구현·실검증을 계속한다.

## 현재 접근 증거

사용자 후속 승인: Wonder 대신 가용한 모델 사용. 공식 목록에 있는 Standard `muse-spark-1.3` 선택; SRS 20.8에 적용했다. 아래 Wonder 결과는 원래 모델의 이력이며 이후 G0/G4는 승인된 모델의 실제 호출 증거로 평가한다. Contributor 모델을 선택하지 않는다.

`docs/evidence/wonder-live.json`: 2026-10-27 15:08 KST, 공식 `GET /v1/models` HTTP 200, 정확한 `muse-wonder-1.0` 없음. 접근 결과는 `WONDER_MODEL_UNAVAILABLE`이며 추론 요청은 실행하지 않았다. 사용자에게 권한 확보를 요청했고 추가 후 알리겠다는 답변을 받았다. 다른 모델로 대체하지 않았다.

공식 [모델 문서](https://dev.meta.ai/docs/models)는 Wonder의 한국 비가용을 명시한다. [지리 정책](https://dev.meta.ai/legal/geographic-use-policy)은 실제 서비스 가용성과 개별 모델 제한을 구분한다. 이 문서만으로 계정 접근을 추정하지 않고 정상 인증 경로의 실제 결과를 기록한다. 우회 접속은 사용하지 않는다.
