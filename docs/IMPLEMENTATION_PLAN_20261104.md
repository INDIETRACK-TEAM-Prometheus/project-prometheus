## 2. 실행 구조

캡처 → MediaPipe/WebEyeTrack → 양안 특징/구면 후보 → 화면 교정 → 원본/표시용 시선 → 현재 attention 상태를 지속 갱신한다. 장면 RGB·카메라 행렬·world version은 같은 frame ID로 보존한다.

빠른 경로는 시선 → 최신 유효 SAM 마스크 hit-test → 엔진 raycast/해당 프레임의 모델 깊이 → 현재 객체/좌표 → 준비된 가설 조회·표시다.

느린 경로는 최신 장면 → SAM/Depth Anything → 객체·상태·기억 갱신 → 다음 객체 후보 → Spark 열린 가설 생성이다. 실행 중 항상 스케줄러가 살아 있고, 매번 최신 관측을 받아 다음 작업을 결정한다. 클릭·응시 종료·장면 정지를 추론 시작 조건으로 삼지 않는다.

호출은 무한 병렬 대신 공급자별 진행 1개 + 최신 대기 1개로 제한한다. 새 프레임만 도착했다는 이유로 모든 호출을 취소하지 않는다. 관련 상태 변경·정지·세션 교체 시에만 취소/무효화한다. 같은 상태의 중복 호출은 결과 재사용·관측 변화로 조절하고 실제 비용·rate 제한을 계측한다. 고정 30초와 현재 비용 예약 정책의 충돌을 실제 가격/계정 제한 확인 후 수정한다. 사용자가 승인한 유료 호출을 숨은 고정 예산으로 막지 않되 명시적 상한/공급자 제한은 상태로 보고한다.

## 3. 수학 계약

### 3.1 검출점과 안구 모델

관측점은 MediaPipe의 모델 예측 좌표다. 눈꺼풀·눈썹·홍채·추가 동공 검출 결과를 종류와 출처로 기록한다. MediaPipe 홍채 중심을 실제 동공 경계 검출로 표시하지 않는다. 가려진 점에는 missing/visibility/quality를 기록하고 과거 좌표를 현재 검출로 복제하지 않는다.

각 눈 e의 중심 c_e, 반지름 R_e, 좌표계와 단위를 가진 구면을 추정한다. 최소 30개 표면점(각 눈, 총 60개 이상)을 단위 방향 q_i로 분포시킨다:

`p_ei = c_e + R_e q_i`, `||q_i|| = 1`, `n_ei = (p_ei - c_e)/||p_ei - c_e||`.

구면 표본점은 생성된 모델 노드이며 독립 검출점 30개라는 뜻이 아니다. 눈꺼풀·눈썹은 별도 비구면 노드다. 고정 구면 노드의 법선 자체는 새로운 시선 정보가 아니므로, 관측 영상과 구면의 대응·추정 안구 회전이 필요하다. 2D 점을 임의 깊이로 올리고 실제 3D로 주장하지 않는다.

카메라 내부 파라미터 K와 왜곡을 확보하고 알려진 화면 표적을 보며 개인별 중심·반지름·회전·시선축 오프셋을 추정한다. 영상 재투영 오차와 표적 오차를 강건 손실로 최적화하고 반지름 prior/시간 연속성을 규제한다. 단일 카메라에서 모호한 파라미터는 고정 prior와 추정 불확실도로 남기며 측정값으로 표시하지 않는다. 얼굴 이동은 좌표계 변화로 분리한다.

### 3.2 법선·각속도·시선축

안구 회전 Q_e(t)에 대해 `n_ei(t) = Q_e(t) q_i`. 같은 좌표계에서 `v = (p(t)-p(t-dt))/dt`, `angle = atan2(||n_prev × n||, n_prev · n)`, `angular_speed = angle/dt`를 계산한다. dt<=0, 프레임 누락, blink, 유실 후 재등장에서는 차분을 보류/초기화한다.

홍채/동공 평면의 법선은 optical-axis 후보다. 개인별 kappa 보정 회전으로 visual-axis 방향 d_e를 추정한다. 모든 표면 법선이 시선 방향이라는 가정은 사용하지 않는다.

### 3.3 양안·화면·깊이

양안 광선 `r_L(t)=o_L+t d_L`, `r_R(s)=o_R+s d_R`, t,s>=0의 최근접점을 풀고 중간점·두 광선 간 거리·수렴각을 기록한다. 거의 평행하거나 뒤쪽 교차, 과도한 불일치는 깊이 unavailable이다. 수렴 깊이와 화면 표면 깊이를 구분한다.

화면 평면 (p0,n)에 대해 `t = dot(p0-o,n)/dot(d,n)`으로 교차점을 구한다. 평행/뒤쪽/화면 밖을 검사하고 화면의 물리 크기와 basis로 픽셀화한다. 정상 노트북 거리를 고정 1.5m로 대체하지 않는다.

가상 화면의 2D 응시점을 가상 카메라 ray로 역투영해 엔진 표면 교차점을 얻는다. metric axial depth z를 사용할 때 `X_cam = z K^-1 [u,v,1]^T`, `X_world = R X_cam + t`. ray range와 axial z, CSS 픽셀과 모델 픽셀, crop/resize/반전을 명시한다. 엔진 깊이, Depth Anything 추정 깊이, 양안 주시 깊이는 별도 필드다.

### 3.4 화면 보정과 시간 필터

`screen_xy = A raw_xy + b`를 ridge/강건 회귀로 피팅하고 affine의 축 범위·offset·shear를 검증한다. 랜드마크 잔차 모델과 기본 출력은 별도 ablation으로 비교한다. 학습·선택·최종 시험 표적을 분리하고 가장자리 포함 미사용 위치를 시험한다.

표시·객체 선택에는 인과적인 One-Euro 또는 Kalman 후보를 비교한다. 원본 기록은 보존한다. jitter 감소와 saccade 지연을 동시에 평가하고 현재 속도/필터 상태를 저장한다. 잘못된 입력을 부드럽게 보간해 정상 측정으로 표시하지 않는다.

### 3.5 그래프와 다음 시선

노드: 관측 눈 영역 + 모델 구면점(각 눈>=30). 특징: 출처, 위치, 법선, 변화, quality/missing mask, 정규화 눈 이미지 임베딩. 엣지: 공간 이웃·홍채/눈꺼풀 관계·양안 대응·과거→현재 시간 연결. 개인화 좌표 정규화와 vector/scalar 특징 구분을 유지한다.

EGNN의 거리 기반 메시지와 등변 좌표 업데이트 또는 temporal GNN을 구현·학습한다. 법선 벡터를 일반 scalar처럼 넣고 등변성을 주장하지 않는다. 출력은 양안 unit gaze/불확실도, 보정된 화면점, `P(next_object | gaze_history, scene_history)`다. 실시간 예측에 미래 프레임을 넣지 않는다.

학습된 가중치 확보→입력/라이선스/버전 확인, 또는 허용된 로컬 표적 영상으로 실제 학습→독립 시험이 필수다. 무작위 가중치 GNN을 활성화하지 않는다. 30~60초 개인 교정만으로 범용 GNN을 학습했다고 주장하지 않는다. 미확보 시 연구 Gate는 미통과로 남기며 기존 모델을 검증된 기준선으로 사용한다.

일정은 목표이며 달성 보장이 아니다. GNN 모델/학습 자료 확보 실패나 실측 정확도 미달은 11/01에 위험으로 공개한다. 제출용 동작 경로를 유지하더라도 누락된 전체 요구를 완료 처리하지 않는다.
