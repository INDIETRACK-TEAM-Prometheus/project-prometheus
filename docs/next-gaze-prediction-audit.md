# Next-gaze prediction status

The runtime now supplies linked current-frame tracked objects, scoped by perception generation and map epoch, as candidate IDs and pixel bounds. Tentative and ambiguous observations are withheld. With no eligible candidate set the result is null; an empty ranking is an abstention. The reasoner requests a separate, bounded ranking for 1 second, restricted to those IDs and `unknown` or `outside_view`, and rejects invented IDs. It remains a hypothesis and is separate from action scenarios. Replay uses the same recorded candidates for each profile and requests its chosen 1, 3 or 5 second horizon. Labels are never sent to the reasoner.

The research ledger retains published rankings and cutoff candidate snapshots. Replay records returned rankings, but comparison metrics still require separately supplied predictions and labels; they are not automatically matched. An independent evaluator must establish future labels and map them to the prediction-time target space, including ambiguous identities, tracking resets and objects outside view. Actual tracking association accuracy, provider schema behavior, calibrated timing, model accuracy and the meaning of predictions remain unverified. There is no real held-out evaluation and T08 remains not assessed. No provider calls were made for this change.
