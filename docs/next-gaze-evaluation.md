# Next-gaze comparison

`runEvaluation` accepts an optional separate `comparisons` array. Each record identifies a selected test decision by zero-based `decision`, `profile`, and `horizonMs`, and supplies independently obtained `targetId`, `abstained`, and `rankedTargetIds`. IDs are exact categorical identifiers in a common externally defined target space. An abstention has an empty ranking. Optional `probabilities` must align with the complete ranked categorical distribution, be descending, and sum to one; the report gives mean top-ranked probability and multiclass Brier score for that subset. The caller is responsible for label validity, a common target space and predictions generated without access to labels. The runner cannot verify these facts. Comparisons are never included in model requests.

Each profile and horizon reports coverage over supplied labeled comparisons and Top-1/Top-3 accuracy among non-abstentions. Missing comparisons, and uncertainty without supplied probabilities, remain not assessed. Counts describe supplied records, not dataset completeness. This is an offline scoring interface, independent of reasoner execution and its scenario abstention. Scenario action text does not establish a next gaze target and is never converted to one. No real held-out labels or predictions are included; the provider CLI does not ingest comparisons. An actual assessment requires externally generated predictions and ground truth in the same predeclared target space, and independent provenance and split validation. T08 remains not assessed.
