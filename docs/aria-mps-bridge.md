# Aria Gen 2 MPS CSV bridge

`src/aria/mps_csv.py` converts documented Gen 2 MPS general gaze or closed-loop trajectory CSV rows into JSONL. Run `python src/aria/mps_csv.py pose data/aria/closed_loop_trajectory.csv` or replace `pose` with `gaze` and provide a matching gaze file. `--cutoff-us` limits emitted source timestamps; it does not make postprocessed results causal. Pose uses `T_world_device`, metres, quaternion XYZW, and `graph_uid`; gaze uses combined yaw/pitch in radians in the central pupil frame. Device timestamps are microseconds converted to nanoseconds in the device clock domain, not UTC or a shared session clock. Input file SHA-256 and CSV row identify provenance. Unsupported image, depth, calibration and MPS processing time are null with reasons. All results are `offline_assisted` and must not enter strict online-causal evaluation.

The official public Gen 2 **sample**, not Pilot Dataset, MPS archive was downloaded from `https://www.projectaria.com/async/sample/download/?bucket=core&filename=aria_gen2_sample_data_1_mps_output_dec_2025.zip`. Its size is 384,609,694 bytes and SHA-256 is `17a78565047a569469d9dd2a0d8b1648740f28cfbb7ea6d3699eae5f1c07631d`. `python scripts/aria_verify_sample.py` reads its documented closed-loop trajectory and validates 39,034 rows, one graph ID, from 1,919,650,861,000 to 1,958,683,861,000 device nanoseconds. The archive contains no general eye-gaze CSV; gaze conversion has only synthetic unit tests. Files remain under `data/aria`, outside source control.

The [Pilot download documentation](https://facebookresearch.github.io/projectaria_tools/gen2/research-tools/dataset/pilot/download) requires accepting its license and terms in Dataset Explorer. No such acceptance was made. [Gen 2 installation](https://facebookresearch.github.io/projectaria_tools/gen2/research-tools/projectariatools/installation) lists Windows support as planned; this machine has no WSL distribution, so the official VRS SDK cannot be run here. The source sample is not evidence of Pilot compatibility. Video, gaze from VRS, calibration, depth, time synchronization, RGB alignment, live causal provenance and full replay integration remain unverified. The loader does not reconstruct any of them or claim G3 passed. The CSV field semantics come from [eye gaze](https://facebookresearch.github.io/projectaria_tools/gen2/technical-specs/mps/data_formats/eye_gaze/eye_gaze_outputs) and [trajectory](https://facebookresearch.github.io/projectaria_tools/gen2/technical-specs/mps/data_formats/slam/mps_trajectory).

The matching official public sample VRS was also downloaded from https://www.projectaria.com/async/sample/download/?bucket=core&filename=aria_gen2_sample_data_1.vrs; size 268,194,147 bytes, SHA-256 `52e78d73dfc12b1d551292e0598b2babc7851c83297ebaab318686fb372f5c7f`. It has not been decoded on this unsupported Windows environment.
