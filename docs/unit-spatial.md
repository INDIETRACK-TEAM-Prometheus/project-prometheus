# Spatial geometry unit

**2026-11-01 consistency note:** this records the original geometry unit. Since then actual `sam-3.1` calls have been made on synthetic scenes (`evidence/sam-live.json`, `spatial-live.json`), `src/spatial/tracker.js` links masks over time, and `src/spatial/mask-association.js` adds `munkres` global assignment (`mask-association.md`). The statements below that SAM is blocked or that no tracker exists are superseded. The geometry math and limits still apply. The live background path does not yet use persistent track IDs (audit A03), and G2 remains not_passed.

This is a dependency-free, synthetic geometry foundation, not a 3D engine, SAM integration, object tracker, or end-to-end G2 acceptance. No inference input is produced from engine ground-truth IDs. Callers must keep evaluation channels separate.

`pixelRay` uses image +x right, +y down, camera +z forward, with pinhole intrinsics and a row-major rigid camera-to-world transform in metres. Renderer adapters must explicitly convert their own axis, handedness, matrix layout and z-buffer; no such adapter is implemented. `firstSurface` intersects synthetic spheres and finite rectangles, returning only the nearest point and provenance, or null with a reason. `unprojectDepth` supports metres in axial_z and ray_range conventions; invalid depth, unscaled monocular depth and nonlinear z-buffer are withheld. Glass, reflection, holes, boundary confidence and alignment must be marked invalid by the caller; these functions do not infer those conditions.

`associateMasks` uses caller-provided discrete uncertainty samples and observed segmentation/tracker masks. Coverage scores are not probabilities; overlaps can sum above one. All masks must be causally verified and no later than the cutoff. It does not perform semantic labeling or persistent identity matching. The calling pipeline must enforce same-frame calibration and the total SYNC budget before invoking geometry or association. Geometry returns a gaze hit, not an object anchor. `compareAnchors` requires an explicit rigid old-to-new map transform across map changes; it does not itself classify physical motion or model uncertainty. Retain original coordinate observations and transform provenance externally.

SAM 3.1 provider model identity, actual endpoint, schema, access, license and live invocation remain blocked/unverified (API-01/02). No substitute is claimed. Synthetic tests cover math and causal cutoff only; T02 engine integration, T03 actual SAM, tracking/identity, dynamic motion, synchronization and T14/T17 end-to-end are not evaluated. Run `node --test test/spatial.test.js`.

## Synthetic WebGL world

`createWorld(canvas)` in `src/spatial/world.js` creates a WebGL perspective scene in metres with moving boxes, a moving camera, a depth buffer and opaque surface occlusion. It requires browser WebGL; it has no external assets or dependencies. `animate()` starts a requestAnimationFrame loop; `render(timeMs)` draws the exact synthetic scene at a monotonic timestamp; `getFrame()` returns the current canvas, frame ID, render time, viewport, intrinsics and row-major camera-to-world matrix. `getDepthAt(x,y)` returns current axial metric depth; `raycast(x,y)` returns first current visible surface point and range; `project(point)` maps a world point to pixel coordinates; `dispose()` stops animation and releases resources. Pixel coordinates are canvas backing pixels, not CSS pixels. Canvas resize invalidates the prior frame until rerender. `getFrame().image` is the live canvas, not an immutable snapshot: callers that need a historical frame must copy it at render time. Rendering time is not verified presentation time; display timing remains unknown and downstream alignment must withhold until supplied.

The engine's ground-truth object identities, future state and hidden geometry are never returned by the production sensor interface. Depth/ray intersection is computed from the same triangles as rendering rather than reading a nonlinear depth buffer. `raycastFrame(frame,x,y)` reconstructs the exact deterministic geometry and camera for a retained frame, not the current scene. Frames are retained up to `maxFrameHistory` (default 300, maximum 1000); an evicted frame returns null and `frame_unavailable_or_evicted`. The stored metadata is bounded; it is not a historical image buffer and evidence images must be independently copied and managed. `markPresented({presentMs,displayUncertaintyMs})` attaches an explicit estimated presentation time to the current frame, with a strictly positive uncertainty; it does not measure panel emission. Supply the estimate in the same monotonic clock as `renderTsMs`, and enforce the total synchronization budget before association. `animate()` uses the requestAnimationFrame timestamp directly; explicit `render` uses the supplied time. No universal display uncertainty is assumed.

Tests validate the shared synthetic geometry mathematically; browser rendering and pixel/depth agreement remain to be validated in an actual WebGL browser, and this does not validate SAM or G2.
