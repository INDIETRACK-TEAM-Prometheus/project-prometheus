# Prometheus — 초기 로컬 연구 프로토타입

Node.js 18 이상이 필요합니다. 외부 패키지 설치나 API 키 없이 실행합니다.

```sh
cd prometheus
npm test
npm start
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. 카메라는 **카메라 시작**을 명시적으로 누르고 브라우저 권한을 허용할 때만 켜집니다. 정지 또는 세션 삭제 시 트랙을 중지합니다. 원시 영상은 디스크에 저장하거나 원격 전송하지 않습니다. 일시정지는 트랙을 비활성화하지만 카메라 권한을 해제하지 않습니다; 완전히 중단하려면 정지를 사용하세요. 진단 숨기기는 관찰 화면만 남깁니다.

이것은 G1 완료 데모가 아닙니다. 화면은 실제 3D 엔진이 아닌 원근 일러스트이며 독립적으로 움직입니다. eye landmark, 양안 크롭, 시선 추정, 교정, viewport 매핑, 실제 Depth와 SAM, 공간 연결, 모델 예측은 아직 없습니다. 가짜 눈 크롭이나 가짜 예측을 보여주지 않습니다. 테스트된 정렬·증거 버퍼·메모리·캐시 함수는 독립 기초이며 화면에 실제 센서 데이터가 연결되어 있지 않습니다. 시선 및 dwell 외의 신호를 사용자 의도 입력으로 쓰지 않고, 시선은 세계를 조종하지 않습니다. 외부 행동 실행은 없습니다.
