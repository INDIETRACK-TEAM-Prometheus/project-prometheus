# 2026-11-04 영상 제출 데모 — 사용자 확정 요구

확정일: 2026-10-31 KST. 이 문서는 구현 완료나 Gate 통과 증거가 아니다.

## 사용 조건

- 사용자 1인, 노트북 화면 위 중앙 내장 웹캠, 정면 자세.
- 평소 노트북 작업 거리. 이전 1.5m ±0.5m는 실사용 거리로 고정하지 않는다.
- 최초 교정 30~60초, 명시적 재교정 전까지 저장·재사용 목표.
- 현재 보고된 문제: 상하좌우 시선 범위 축소, 심한 흔들림.
- 브라우저 UI, 로컬 서버·가용 컴퓨팅 자원 사용 가능.
- 11월 4일 제출용 실제 동작 영상. Aria 장비는 없으며 필요 조건으로 두지 않는다.

## 데모 출력

1. 화면 2D 응시점.
2. SAM 분할 결과와 결합한 현재 응시 객체.
3. 가상 세계의 표면 응시 좌표와 깊이. Depth Anything 계열 적용 요청.
4. 다음 응시 위치·객체 예측.
5. 관측 근거에 기반한 열린 행동·의도 가설. 실제 생각을 읽거나 확정한 사실로 표현하지 않는다.

장면 표면의 3D 교차점, 영상에서 추정한 깊이, 양안으로 측정한 주시 깊이는 서로 구별한다. 렌더러 깊이를 Depth Anything 출력이라고 표시하지 않는다.

## 지연 목표와 측정

사용자 추가 명확화: 앱 실행 중 백그라운드에서 시선 기반 attention 추론을 지속한다. 시선 이동이나 클릭이 발생한 뒤에야 LLM을 호출하는 구조가 아니다. 최신 관측을 모으는 지속 루프와 선행 추론을 유지하고, 사용자에게는 유효한 준비 결과를 조용하고 빠르게 갱신한다. API 요청은 중복·무한 병렬로 보내지 않고 진행 중 작업과 최신 관측을 관리한다. 정지 시 루프와 요청을 종료한다.

사용자 목표는 LLM 열린 추론을 포함해 자연스러운 200ms 이하 반응이다. 아직 달성 증거가 없다. 기존 CTO_REVIEW에는 Spark 합성 응답 6,560ms가 기록되어 있다.

- 시선 프레임 처리→화면 표시, 객체 선택, Depth, SAM, LLM 첫 출력/완료를 각각 측정한다.
- 미리 생성한 유효 가설을 표시하는 지연과 새로운 LLM 추론 생성 지연을 분리한다.
- 캐시된 가설은 해당 장면·객체·관측 시점과 연결하고, 새 관측으로 생성한 답인 것처럼 표시하지 않는다.
- 평균뿐 아니라 p50/p95, 실패·드롭률, 결과 나이를 기록한다.

## 데이터 및 키

사용자는 얼굴 전체 영상·눈 크롭·랜드마크·시간·교정 표적 등 로컬 학습/분석 자료 저장을 허용했다. 기존 문서의 원본 비저장 방침과 충돌하는 범위에서는 이 최신 사용자 지시를 따른다. 이는 저장 구현이 이미 존재한다는 의미가 아니다.

- 원본 자료는 로컬에 저장하고 Git 커밋 및 외부 API 전송 대상에서 제외한다.
- API 키는 서버 환경에만 두며 존재 여부만 확인한다. 값은 브라우저·소스·로그에 넣지 않는다.
- 세션 ID·프레임 ID·시각·모델 버전·교정 버전으로 추적 가능하게 한다.
- 저장 실패·디스크 부족을 표시하고 카메라 세션을 무한 메모리 버퍼로 대체하지 않는다.

## 우선순위

1. 시작/교정/재시작 안정성 및 원본 자료의 로컬 기록.
2. 개인별 화면 좌표 교정의 범위 축소와 흔들림 개선, 저장·복원.
3. 현재 프레임의 SAM 객체와 시선 연결, Depth Anything 실제 추론과 깊이 출처 표시.
4. 다음 응시 후보 및 선행 생성한 열린 가설의 인과적 표시.
5. 동일 장면에서 처음부터 끝까지 실제 영상 시연과 지연·실패 기록.

EGNN·구면 안구·시간 모델은 공개 가중치·입력 의미·실측 개선을 확인한 경우 도입한다. 임의 초기화한 모델이나 구면 가정을 검증된 3D 시선으로 표시하지 않는다. 합성/단위 테스트만으로 실제 정확도 Gate를 올리지 않는다.

## 10월 31일 조사 및 코드 감사

- 실제 장비: Intel Iris Xe. Python 3.12에 torch/cv2/onnxruntime/transformers 미설치. 고급 NVIDIA GPU 벤치마크를 이 장비의 성능으로 인용하지 않는다.
- 현재 앱은 지속 LLM 추론이 아니다. 완료된 gaze event와 광학 정렬 조건에 의존하는 통합 경로, 5초 간격 SAM 탐색, 별도 30초 간격 잠정 Spark 시험 경로가 존재한다. 첫 구현 단위는 최신 관측만 유지하는 백그라운드 coordinator와 유효 가설 캐시 연결이다.
- 렌더러에는 raycastFrame/getDepthAt 등 합성 기하가 있지만 실제 Depth Anything 모델은 없다. 우선 검토할 모델은 [Depth Anything V2 Metric Hypersim Small](https://huggingface.co/depth-anything/Depth-Anything-V2-Metric-Hypersim-Small). [공식 metric 경로](https://github.com/DepthAnything/Depth-Anything-V2/blob/main/metric_depth/README.md)의 가중치·출력 단위 및 실제 로컬 런타임을 검증한다. 상대 깊이를 미터로 간주하지 않는다.
- 현재 교정은 27+27점, 클릭 방식이며 adapted 상태는 메모리에만 있다. 최초 30~60초 교정과 저장 복원 요구는 미충족이다. 저장된 버전별 적응 표본의 재적용 및 검증 가능성을 확인한다.
- 범위 축소: 기존 fitCalibration을 활용한 개인별 2D 출력 affine 보정을 우선 비교한다. 흔들림: 표시용 인과적 필터를 비교하되 원본과 필터 출력 및 지연을 분리 기록한다. 현재 반복 격자 비교를 새로운 위치에 대한 일반화 증거로 표시하지 않는다.
- [EMC-Gaze](https://arxiv.org/html/2603.12388)는 눈 중심 161개 랜드마크 EGNN 및 세션 ridge 교정을 설명하지만, 조사한 공개 저장소에서 해당 encoder 가중치를 확인하지 못했다. [LightGazeNet](https://eyelignai.github.io/lightgazenet/)도 공개 코드 준비 중으로 표시되어 제출의 필수 경로로 두지 않는다.
